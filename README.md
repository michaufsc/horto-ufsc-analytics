# 🌿 Horto UFSC - Dashboard Analytics

Dashboard interativo para análise de dados do portal de plantas medicinais do Horto Didático UFSC.

## 🚀 Funcionalidades
- Análise de tráfego do Google Analytics 4
- Perfil demográfico dos usuários
- Ranking de espécies medicinais
- Painel em tempo real

## 📊 Dados
- Dados do Google Analytics 4 - Property ID: 750410485227
- Período: 2025 - 2026
